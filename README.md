# TCL — XML-прайс рекомендованих роздрібних цін (РРЦ)

Посилання для автоматичного підтягування цін інтернет-магазином:

**https://alexgerua.github.io/TCL-price-XML/price.xml**

- Формат — YML (`yml_catalog`), кодування UTF-8.
- Ціни — рекомендовані роздрібні, **у гривнях**.
- Оновлюється автоматично щодня о 18:00 (Київ) з даних TCL. У файлі лише моделі, які є в наявності.
- Для кожного товару: назва, модель (`vendorCode`), категорія, серія, РРЦ, фото.

Якщо ви передаєте ціни на прайс-агрегатори (Hotline, ek.ua тощо) — підключіть цей файл
до свого сайту або фіду (feed), щоб ціни не були нижчими за РРЦ.
